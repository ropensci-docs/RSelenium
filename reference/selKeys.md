# Selenium key mappings

This data set contains a list of selenium key mappings. selKeys is used
when a sendKeys variable is needed. sendKeys is defined as a list. If an
entry is needed from selKeys it is denoted by key.

## Usage

``` r
selKeys
```

## Format

A named list. The names are the descriptions of the keys. The values are
the "UTF-8" character representations.
