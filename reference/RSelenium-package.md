# An R client for Selenium Remote Webdriver

These are R bindings for the WebDriver API in Selenium 2. They use the
JsonWireProtocol defined at
https://github.com/SeleniumHQ/selenium/wiki/JsonWireProtocol to
communicate with a Selenium RemoteWebDriver Server.
